# DR MULTISERVICES — aperçu V4

Site statique hébergé sur GitHub Pages. Domaine commercial et DNS inchangés.

Le formulaire prépare un message WhatsApp ; le visiteur doit le vérifier et l’envoyer. Aucun serveur PHP, Python ou SMTP n’est publié.

Aperçu non destiné à l’indexation : les textes commerciaux hérités et les illustrations restent à valider avant une bascule du domaine.
